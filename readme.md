# Yo, it's lowkey

## Features
- **Smart Notifications**: Personalized push notifications that rotate messages based on relationship type
- **On-Demand Nudge**: Manually trigger an immediate nudge for any person from their detail view
- **Priority Scheduling**: Notifications are prioritized by relationship importance, frequency, and urgency (max 64 concurrent)
- **Nudge Tracking**: See when each person was last nudged, with a clear "never nudged" indicator
